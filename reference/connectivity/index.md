# Connectivity

| Interface   | Address                   | Peers                       | Ports                                                                                                                                                                                                                                                                                                                                                                                           |
| ----------- | ------------------------- | --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| API         | `api.address`             | Operators, Prometheus       | TCP `api.port` (`5020`)                                                                                                                                                                                                                                                                                                                                                                         |
| SIP         | `sip.addresses`           | Phones, Application Servers | P-CSCF: UDP and TCP `pcscf.port` (`5060`) P-CSCF, IPsec: UDP and TCP in ESP, `pcscf.ipsec.server_port` (`5063`), `pcscf.ipsec.client_ports` (`5064`, `5065`) I-CSCF: UDP and TCP `icscf.port` (`5070`) S-CSCF: UDP and TCP `scscf.port` (`5080`) MCPTT, `direct` mode: UDP and TCP `mcptt.port` (`5090`) Voice of calls over SIP trunks: UDP `ibcf.media.min_port`–`max_port` (`10000`–`19999`) |
| Carriers    | `ibcf.external.addresses` | SIP trunks                  | SIP: UDP and TCP `5060`, TLS `5061` Voice: UDP `ibcf.media.min_port`–`max_port` (`10000`–`19999`)                                                                                                                                                                                                                                                                                               |
| Diameter    | `diameter.address`        | HSS, PCRF, SMSC, MME, SMSF  | TCP or SCTP `diameter.port` (`3868`)                                                                                                                                                                                                                                                                                                                                                            |
| MCPTT media | `mcptt.media.address`     | MCPTT clients               | UDP `mcptt.media.min_port`–`max_port` (`20000`–`20999`), `mcptt.media.control_port` (`21000`)                                                                                                                                                                                                                                                                                                   |
| N5          | `n5.notify.address`       | PCF                         | HTTP/2, optionally with mutual TLS, `n5.notify.port` (chosen by the system)                                                                                                                                                                                                                                                                                                                     |

Defaults are in parentheses.
